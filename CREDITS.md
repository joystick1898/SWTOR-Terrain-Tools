# Credits and provenance

SWTOR Terrain Tools is an independent Blender add-on maintained and published by [joystick1898](https://github.com/joystick1898). Its original implementation was developed with AI assistance, format inspection, and iterative testing using locally extracted terrain supplied by the project user. The community source preparation retained the working 1.0.1 algorithms and added readable formatting, comments, documentation, and packaging. Later versions add the repair, performance, and resolution changes recorded in the [changelog](https://github.com/joystick1898/SWTOR-Terrain-Tools/blob/main/CHANGELOG.md).

The project author field credits **SWTOR Terrain Tools contributors**. Repository maintenance, AI-assisted implementation, and acknowledgments below describe different contributions; they do not claim that the named upstream authors wrote or endorsed this add-on. Release installers include this credits file and the GPL license.

Related tools and research context:

- [ZeroGravitas / SWTOR Slicers ZG SWTOR Tools](https://github.com/SWTOR-Slicers/ZG-SWTOR-Tools): the area-import workflow this add-on complements.
- [UltimaKaosXIII's SWTOR Terrain Extractor 2](https://github.com/UltimaKaosXIII/STE2): terrain mesh extraction and the grid/topology conventions used during validation.
- [Jedipedia](https://jedipedia.net/): File Reader inspection and terrain previews used to investigate the source data and compare appearance.
- [Blender](https://www.blender.org/) and [NumPy](https://numpy.org/): host application, mesh/image APIs and numerical processing.
